# Шлюз

Партийная игра на 4–12 человек (недостающих заменяют боты). Открывается в браузере на телефоне или компьютере, у каждого игрока свой экран.

1. **Тревога.** Каждый получает случайного персонажа и случайную точку старта (дом, парковка, парк). На карте сверху бежите по точкам, берёте и выкладываете вещи, пока идёт таймер. Опоздали к выходу: рана и потерянная вещь.
2. **Шлюз.** Случайное убежище с дефектом, мест хватает половине. Каждый раунд: открыть карту или вещь, событие, обсуждение, голосование. Рюкзак уходит вместе с изгнанным.
3. **Вылазки.** Доброволец проходит историю на своём экране и сам решает, рассказывать ли её остальным. Может не вернуться.
4. **Исход.** Игра считает, хватило ли составу еды, воды, медицины и прочего, и показывает хронику для убежища и для лагеря снаружи.

## Запуск

Нужен Node.js 18+. Зависимостей нет.

```bash
npm start
```

Откройте `http://localhost:3000`. Чтобы играть с друзьями, сервер должен быть доступен им по сети: общий Wi-Fi и адрес компьютера либо любой хостинг, который запускает `node server.js` (порт берётся из переменной `PORT`).

```bash
npm test
```

## Как менять игру

Весь контент лежит в `content/scenario.json` и читается при создании комнаты, перезапуск не нужен:

| Раздел | Что это |
|---|---|
| `locations` | точки старта: время, вместимость, зоны на карте (`x`, `y` от 0 до 100), скорость бега `secPerUnit` |
| `items` | вещи: `gives` — вклад в потребности, `size` — места, `vague` + `knownBy` — название для тех, кто не разбирается, `onlyFor` — видят только нужные профессии |
| `professions`, `health`, `hobbies`, `traits`, `secrets` | карты персонажа, `w` — вес при раздаче |
| `bunkers`, `twists` | убежища, их запасы и дефекты, скрытые сюрпризы финала |
| `events` | события между раундами, `minDanger` — с какого уровня опасности выпадают |
| `sorties` | истории вылазок: узлы, варианты, шансы, бонусы за навыки и вещи |
| `baseNeeds`, `outsideNeeds` | сколько нужно на четверых внутри и снаружи |

Сложность (множитель потребностей, шанс сюрприза, допустимое число кризисов) задаётся в `DIFF` в начале `engine.js`.

## Устройство

- `engine.js` — правила игры без сети и таймеров.
- `server.js` — комнаты в памяти, действия по POST, состояние по SSE. После перезапуска сервера комнаты пропадают.
- `public/` — интерфейс.
