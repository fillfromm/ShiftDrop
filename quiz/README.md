# Квиз для вечеринки

Викторина с табло категорий и вопросов, пультом ведущего и кнопкой «ЖМИ!» на телефоне каждого игрока.

## Запуск

Нужен только [Node.js](https://nodejs.org) 18+, зависимостей нет.

```bash
node server.js
```

В консоли появятся три ссылки и PIN ведущего:

| Страница | Для кого |
| --- | --- |
| `/` | Игроки: вводят имя и получают кнопку на весь экран |
| `/screen` | Общий экран (ТВ, проектор): QR-код для входа, табло, вопрос, счёт |
| `/host` | Ведущий: открывает вопросы, видит ответы, судит, правит счёт, редактирует вопросы |

Телефоны должны быть в той же Wi-Fi сети, что и компьютер с сервером. Если гости не в одной сети,
разместите сервер на любом хостинге с Node.js и задайте адрес в `PUBLIC_URL`.

## Как идёт игра

1. Ведущий открывает вопрос на табло. Кнопки у игроков становятся активными.
2. Кто нажал первым — отвечает; остальные встают в очередь в порядке нажатия.
3. Ведущий жмёт «Верно» (баллы начисляются, ответ показывается на экране) или «Неверно»
   (баллы снимаются, отвечает следующий в очереди; ошибившийся больше не может нажать на этом вопросе).
4. Счёт любого игрока можно поправить вручную: ±100 или задать точное число.

## Настройка

| Переменная | Значение |
| --- | --- |
| `PORT` | Порт, по умолчанию 3000 |
| `HOST_PIN` | Свой PIN ведущего (иначе создаётся случайный) |
| `PUBLIC_URL` | Внешний адрес сайта для QR-кода, если сервер на хостинге |
| `DATA_DIR` | Где хранить состояние игры и картинки, по умолчанию `data/` |

Вопросы редактируются на странице ведущего во вкладке «Редактор вопросов»; набор можно скачать и
загрузить как `.json`. Цвета и шрифт меняются в переменных в начале `public/style.css`.
Состояние игры сохраняется в `data/state.json` и переживает перезапуск сервера.

QR-код рисует библиотека [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT).
